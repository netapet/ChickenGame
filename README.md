# Goat Kart-ish

A dependency-free, pseudo-3D endless runner built for GitHub Pages.

## Play locally

Open `index.html` in a browser. No build step is required.

## Publish on GitHub Pages

Push these files to a GitHub repository, then open **Settings → Pages** and choose **Deploy from a branch**. Select your main branch and the `/ (root)` folder.

## Replace the art

Swap the files in `assets/` while keeping the filenames (`goat.svg`, `chicken.svg`, and `egg.svg`), or update their paths near the top of `script.js`.
